1. 本矩阵只聚合，不新增规则；某项能力变化必须能指向功能主文档或版本规划。
2. 能力增强导致接口/数据破坏性变化时，登记到冻结决策与文档变更记录。
3. 需要按单个功能查看跨版本时间线时，可另建“具体功能演进索引”，但不得与功能文档并列为第二事实源。
