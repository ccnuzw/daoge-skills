## 2. 备份范围

- 主数据库全量备份与连续增量/WAL 能力。
- migration 版本、扩展与必要配置。
- 应用镜像 digest、前端构建与部署配置版本。
- secret 只备份引用和恢复流程，不把明文复制进普通备份。
- 缓存不作为业务终态恢复源；故障后重建短期状态。

## 3. 演练步骤

1. 选择隔离恢复环境和已知备份时间点。
2. 记录备份标识、开始时间和操作者。
3. 恢复数据库并应用必要增量。
4. 部署对应版本的应用。
5. 验证 schema 与关键业务关系（账户、订单、流水、审计等）。
6. 执行只读 smoke 和一组隔离写入测试。
7. 计算实际 RPO/RTO，记录缺失数据范围。
8. 销毁隔离环境或按证据策略保留。

## 4. 通过条件

- 实际 RPO/RTO 不超过门禁目标。
- 关键业务总账关系一致。
- 敏感数据可按安全流程恢复。
- 没有通过手工覆盖数据来“修复”验证结果。
- 发现的问题有负责人、截止时间和复验批次。
