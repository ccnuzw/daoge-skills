## 完成定义

单个 E2E 用例只有同时满足以下条件才能标记通过：

1. 使用已记录的代码版本或构建标识。
2. 环境、配置模式和测试数据可复现。
3. 自动断言覆盖接口结果与关键数据副作用。
4. 命令退出码为 0，报告和必要日志已归档。
5. 失败分支证明没有不应发生的上游调用、扣费或重复副作用。
6. 真实外部依赖与生产门禁的用例明确区分 local / staging / production-gate。
