## 公共前置

每条场景必须记录：

- build/制品/migration、负载 profile、环境和 fixture 标识。
- 压测工具、模拟器与采集器版本。
- 执行前后 health/ready/metrics 状态。
- 压测机、服务端与模拟器资源余量。
- 清理结果、未清理对象和遗留风险。

## 公共失败条件

出现以下任一情况，批次不得标记 Passed：

- 使用未批准或执行中被修改的负载配置。
- 使用聚合分位数相减等方式伪造指标。
- 压测机、模拟器、网络或采集器成为未量化瓶颈。
- 把预期拒绝、非预期错误和超时混为一个错误率。
- 资源采样中断、报告缺少构建身份或数据无法按 run_id 核对。
- 出现任何业务不变量失败，即使性能分位数达标。
