## 约束清单

| 编号 | 约束 | 适用范围 | 例外与决策 |
| --- | --- | --- | --- |
| GC-01 | <例如：涉及图片上传的功能必须使用共享上传组件与上传接口，不允许用户填写图片 URL> | 全版本 | 无 |
| GC-02 | <例如：金额一律 Decimal，时间一律 UTC 存储、按用户时区展示> | 全版本 | 无 |
| GC-03 | <例如：所有列表接口必须服务端分页并提供最大 page_size> | 全版本 | 无 |

## 使用规则

1. 版本进入开发门禁时，必须对每条约束做适用性检查并记录结论。
2. 功能文档与约束冲突时，先形成冻结决策，再修改功能文档或约束。
3. 新增约束必须说明动机、影响面与生效版本。
