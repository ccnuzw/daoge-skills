# {{活跃版本}} 接口契约

本文件定义接口**公共语义与路由清单**；字段级权威是 [OpenAPI]({{活跃版本}}-openapi.yaml)。单功能接口细节写在功能主文档中。

## 通用响应

```json
{
  "code": 0,
  "data": { },
  "request_id": "req_x"
}
```

- 成功：`code = 0`；失败：`code` 为数值错误码，`error_key` 与提示见[统一错误码](../统一错误码.md)。
- 所有受保护接口必须在服务端校验身份；对象访问必须校验所有权。
- 分页与筛选：服务端分页、稳定排序、`page_size` 上限；参数见对应接口。
- 时间使用带时区时间戳；金额使用 Decimal 或最小货币单位整数。

## 契约与当前路由状态

| 状态 | 含义 |
| --- | --- |
| 已实现 | 路由存在且与契约一致 |
| 部分实现 | 路由存在，字段或行为有差距（功能文档记录） |
| 规划中 | 契约已冻结，路由未实现 |

规划中的接口必须单独成表并显式声明“计划，不是当前可调用路径”；在 OpenAPI 中用扩展字段标注（例如 `x-<项目>-implementation-status: planned`），不得与当前路由混排。文档段落不能代替机器契约：管理侧写接口在进入开发前必须补齐 OpenAPI。
