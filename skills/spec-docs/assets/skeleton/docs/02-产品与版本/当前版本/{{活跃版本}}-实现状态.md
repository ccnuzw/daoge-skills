## 状态使用规则

- **规划中**：已确定范围，尚未进入开发。
- **开发中**：已开始实现，未满足全部功能验收。
- **部分实现**：只覆盖部分接口、部分 UI 或缺少冻结决策要求。
- **基础实现**：主链路已有代码，但未满足全部功能验收。
- **本地验证**：不能作为真实外部依赖或发布门禁的最终证据。
- **待验收 / 已完成**：功能升为“待验收”前，必须在对应功能主文档的“实现与验证”章节填写日期、环境、构建标识、命令/用例和结果。
