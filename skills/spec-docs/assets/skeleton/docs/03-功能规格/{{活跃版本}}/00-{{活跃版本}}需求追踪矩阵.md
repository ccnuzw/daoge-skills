## 覆盖规则

- 版本总览中的每一项必做范围至少映射到一份功能主文档。
- 所有公开业务接口必须映射到功能主文档；新增但接口总表未登记的接口，需要在对应功能实现前回写接口契约。
- 每个高风险功能的每个分支 ID 至少映射一个功能 AC；关键用户链路还要映射 E2E 或发布门禁。
- 矩阵与编号表不一致时，先修正文档再继续开发，不允许跳过。
- 接口、数据或 E2E 映射变化时同步更新本表。
