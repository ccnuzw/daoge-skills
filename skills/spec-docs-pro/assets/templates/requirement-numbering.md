# V{n} 需求编号

本文档为 V{n} 分配稳定编号。编号一旦分配不改变、不复用；功能改名或移动目录不改变编号。编号规则的完整定义见 skill 的 references/status-and-ids.md。

## 编号规则

| 类型 | 格式 | 示例 |
| --- | --- | --- |
| 功能需求 | `V{n}-FR-NNN` | `V1-FR-005` |
| 非功能需求 | `V{n}-NFR-NNN` | `V1-NFR-002` |
| 发布门禁 | `V{n}-RG-NNN` | `V1-RG-003` |
| 跨功能验收 | `V{n}-E2E-NN` | `V1-E2E-01` |
| 功能内验收 | `ACNN`（全称 `V{n}-FR-NNN/ACNN`） | `AC03` |
| 设计分支 | `B{功能号两位}-NN` | `B05-03` |
| 冻结决策 | `DNNN` | `D012` |
| 架构决策 | `ADR-NNNN` | `ADR-0003` |

功能主文档文件名为 `NN-功能名.md`，`NN` 等于 `V{n}-FR-NNN` 的后两位（功能号超过 99 时用三位）。
