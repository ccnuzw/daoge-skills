# {{VERSION}} 发布门禁清单

所有必需项必须由责任人基于当前提交、当前构建和真实环境证据勾选。结构完整不等于允许发布。

## 变更与构建

- [ ] 发布范围与 {{VERSION}} 冻结范围一致，没有未记录的业务语义变更。
- [ ] Git 工作区、提交、构建 ID 和待发布制品唯一绑定。
- [ ] 数据库迁移已评审，并完成前向和回退路径验证。

## 测试、安全与容量

- [ ] 单元、集成、契约和 E2E 必需用例全部通过，无跳过项。
- [ ] 安全基线检查完成，高风险问题已关闭或获得有时限的书面例外。
- [ ] 已批准负载模型下的性能和容量阈值全部通过。

## 部署、回滚与恢复

- [ ] 部署手册已在同等级环境演练。
- [ ] 回滚触发条件、责任人、命令和验证步骤已经确认。
- [ ] 备份可用，恢复演练满足 RPO/RTO，证据仍在有效期内。

## 发布与观察

- [ ] 灰度范围、观察指标、停止条件和扩大流量条件已经确定。
- [ ] 冒烟检查、业务副作用核对和观察窗口负责人已经确定。
- [ ] development、E2E、performance、release 四类报告已绑定当前构建。
- [ ] 发布负责人完成最终批准，批准时间晚于全部证据生成时间。
