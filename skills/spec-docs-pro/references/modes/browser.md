# 模式：生成文档浏览器

适用：为 `docs/` 生成可离线打开的单页文档浏览器（总览、阅读、功能、图谱、演进、时间线 6 个视图）。

浏览器由脚本生成，不要手工编辑 HTML，也不要让 agent 逐字段拼装数据。脚本从文档中提取全部数据，查看器本身不含任何项目数据。

## 步骤

1. **定位 docs。** 确认 `docs/` 路径（可能是仓库根目录下的 `docs`，也可能是用户指定的目录）。
2. **先检查。** 运行：

   ```bash
   node <skill>/scripts/check-docs.mjs --docs <docs路径>
   ```

   错误会让浏览器缺内容（例如没有实现状态表，功能状态显示“未同步”；演进矩阵格式不对，时间线没有阶段）。把与浏览器相关的问题告诉用户：EV*、ST001、ST005、LNK001。是否先修由用户决定，不阻塞生成。
3. **生成。**

   ```bash
   node <skill>/scripts/generate-browser.mjs --docs <docs路径>
   ```

   可选参数：`--out <docs 内的目录>`（默认 `90-参考资料`）、`--project <名称>`、`--config <配置文件>`、`--json`（机器可读摘要）、`--strict`（有数据质量提示时退出码为 1）、`--stamp`（在数据里写入生成时间，默认不写）、`--check`（不写文件，只比较现有产物是否过期，过期时退出码为 1，可放进 CI）。

   输出只由文档内容决定：默认不含时间戳，也不含本机路径，所以同一份文档每次生成的字节完全一致，可以直接提交到仓库后用 `--check` 判断是否忘了重新生成。数据文件超过 `browser.dataWarnKB`（默认 2048 KB）时摘要里会提示体积；文档很多时用配置 `exclude` 排除归档目录。
4. **核对摘要。** 脚本输出项目名、文档数、功能数（以及其中没有实现状态的数量）、决策数、版本列表、能力主线数和数据质量提示。项目名或版本识别不对时，用 `docs/spec-docs.config.json` 修正（模板：`assets/templates/spec-docs.config.json`），然后重新生成。
5. **交付。** 告诉用户两个输出文件的路径，直接双击 HTML 即可离线打开；文档更新后重新运行同一条命令。

## 数据从哪里来

| 浏览器内容 | 来源 | 识别规则 |
| --- | --- | --- |
| 项目名 | `docs/README.md` 或 `01-项目概览/README.md` 标题 | “{项目名} 文档中心 / 文档” |
| 功能清单 | `03-功能规格/**/NN-*.md` | frontmatter `feature_id`；没有时由文件序号推断 |
| 实现状态 | `*/V{n}-实现状态.md` | 含“编号”列和“状态”列的表格 |
| 版本 | `当前版本/`、`后续版本/`、版本路线图表格、`99-历史归档/V{n}-*.md` | 当前版本 = `当前版本/` 中的版本 |
| 能力主线与阶段 | `功能演进矩阵.md` | 每个 `##` 章节下第一列为“阶段”的表格；阶段名以 `V{n}` / `后续` 开头 |
| 功能 → 能力主线 | frontmatter `track` → 配置 `featureTracks` → `具体功能演进索引.md` → 领域名称相似度 | 按顺序取第一个命中 |
| 关键口径 | `V{n}-冻结决策.md` 中状态为“已冻结”的最新 8 条 | 可用配置 `keyDecisions` 覆盖 |
| 图谱 | 以上数据 | 版本路线、能力 × 版本热力图、领域状态分布、风险分布 |

## 常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 功能状态全是“未同步” | 实现状态表缺失，或表格没有“编号”列 | 用 `assets/templates/version-implementation-status.md` 补表 |
| 时间线某版本显示“无阶段” | 该能力主线在该版本确实没有阶段，或阶段名没有以版本开头 | 运行 check-docs 看 EV004；空白不代表取消 |
| 功能关联到错误的能力主线 | 领域名称推断不准 | 在功能 frontmatter 写 `track: {能力主线标题}` |
| 项目名不对 | README 标题不是“{项目名} 文档中心” | 配置 `project.name` 或用 `--project` |
| 图片不显示 | 图片文件不存在 | check-docs 的 LNK001 会列出 |
| 打开页面显示“无法读取文档数据” | 数据文件与 HTML 不在同一目录 | 两个文件一起移动 |
