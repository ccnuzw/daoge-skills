## 0. 前置

本批是界面批里**最吃紧的一批**（界面宪法 §8.2 标注的「核心 KPI」屏）。它不加东西，而是**把创作平台那四条横带收成一条**，并把挤在内容上方的那只队列挪到底部槽去。

## 2. 任务分解

### 2.1 C1 · 四条 chrome 收成一条 48px（含控件清点表）

| 现居 | 控件 | 新家 |
| --- | --- | --- |
| 工具条 | 标题（模式名 + 说明） | 工具条左侧；模式降为标题旁下拉（D1） |
| 工具条 | 适应全部 / 适应选择 | 工具条（图标按钮，`title` 放全文） |
| 工具条 | 新建批次 | 工具条（B3 刚落位，保留） |
| 工具条 | 编辑模式开关 | 工具条「编辑」开关 |
| 工具条（编辑时） | 选择 / 拖动画布 / 自动整理 | 编辑开启时就地**在同一行内换段**展开 |
| 工具条（编辑时） | 编辑设置：重置视图 / 撤销 / 重做 / 模板 / 吸附 / 小地图 / 快捷键 | 保持现「编辑设置」浮层不变 |

**实现要点**：
- 单条用 CSS grid：`[标题/模式] [编辑时工具] [弹性空] [筛选] [统计] [搜索] [更多]`；
- `height: 48px` 固定行高，**不因选中态或编辑态增高**（编辑态只换段，不许再加一条）；
- 打 `data-region="toolbar"`（0.0 的陷阱 1）——**这是让 KPI 可测的前提**。

### 2.2 C2 · 统计进浮层、保存态变指示点

- 统计长串（资产·运行项·已选·异常·分组·标注·虚拟化·上限·批量同步）**一个不丢**，全部进浮层（G18 ②）；
- 浮层入口是工具条上的「统计」按钮（D3），打开后是可复制的数字表；
- 保存态：常态一个**指示点**（已保存 / 保存中 / 失败三色，`title` 说明）；**失败时必须有一行文字**
  （`aria-live="polite"`）——「变红点」不算通知到位。

### 2.3 C3 · Aside 统一

三个右栏（画布批次检查器 `lineage-inspector` / 全局资产来源与评审 `asset-inspector` / 队列展开面板）合成一个：

- 容器唯一，带 `data-region="aside"`（G20 ①）；宽度与开合规则一处定义；
- 三种内容按选中与操作**互斥渲染**（批次 / 资产 / 队列展开），优先级：显式打开 > 选中节点 > 无选中；
- **无选中时不许空白**——显示这一批的指标 + 最近动作（C5、G20 ③）。

### 2.4 C4 · 队列贴底让位（队列三态）

- **位置**：`RequestQueueDock` 从「内容之上」挪到 `[data-region="page"]` **之后**（G19 ①）——首元素 y 就靠这一步；
- **三态**：空闲（一行摘要 ≤48px）/ 折叠（composer + 一行摘要，仍 ≤48 的常驻部分）/ **展开**（≤min(320px, 35%×H)，S1 预算）；
- **让位**：展开时画布**不遮挡**（画布可视高度按槽高收缩，不许浮层盖住节点）；
- **互斥（I1）**：composer **常显**；选片（选区/放大层）时**展开层自动收起**，但 composer 不挡；
- alert（需要你回答的追问）**常显不折叠**（S7）——折叠只折「已完成的历史」。

### 2.5 C5 · 指标四项进 Aside 顶部

- 四项（**D2 定名**）从既有事实源派生（`roundOutputSummary` + round 状态，**不新增 fetch**）；
- 无选中也能看到（默认显示当前批次）；有选中时仍在顶部一行；
- 指标是**状态**不是动作：点它不跳页（要跳有既有入口）。
