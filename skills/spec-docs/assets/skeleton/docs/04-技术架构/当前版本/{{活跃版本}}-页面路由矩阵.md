## 路由变更规则

1. 新增页面必须登记路由与关联功能；没有功能归属的页面不允许上线。
2. 路由调整同步功能主文档“页面与交互”章节与前端测试。
3. 权限列必须与接口鉴权一致，冲突时以接口鉴权与冻结决策为准。
