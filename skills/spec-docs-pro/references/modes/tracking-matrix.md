# 模式：需求追踪矩阵

适用：生成或更新 `03-功能规格/V{n}/00-V{n}需求追踪矩阵.md`。

## 步骤

1. **读全部功能主文档**，提取：编号、接口清单、读写数据、AC 编号与测试资产、技术设计分支范围、引用的决策和 E2E。不要猜测或编造映射。
2. **按 `assets/templates/tracking-matrix.md` 写入。** 只写引用关系，不复制业务细节。链接用相对路径。
3. **找缺口。** 运行 `check-docs.mjs --json`，结合矩阵找出：没有接口映射的功能、没有测试资产的 AC、没有所有者的数据表、没有被任何功能引用的决策。缺口登记在矩阵“覆盖缺口”表中。
4. **交付。** 统计（功能数、接口数、AC 数、缺口数）和缺口清单。补齐缺口要用户确认后再做。
