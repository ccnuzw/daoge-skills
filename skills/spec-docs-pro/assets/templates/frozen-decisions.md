# V{n} 冻结决策

本文档解决 PRD、公共文档、功能文档和当前实现之间的口径冲突。状态为“已冻结”的决策是 V{n} 开发与验收依据；代码与之不一致时，修改代码或发起新的决策，不保留两套行为。

需要记录长期架构影响的选择同时写 [ADR](ADR/README.md)：本文件冻结结论，ADR 解释为什么这样决定。

维护规则：

- 编号 `D001` 起递增，跨版本不复用、不重排；最新决策可以放在最上方。
- 状态只能是：草案 / 已冻结 / 已取代 / 已撤销。被取代时写“已取代（由 D0NN 取代）”，原文保留。
- 每条决策必须列出影响范围，并在受影响的功能主文档“来源与追踪”中引用编号。
