## 4. 数据演进规则

1. 新增字段要贯穿 migration、领域、服务、接口、前端类型。
2. 破坏性变更必须先决策、后迁移，并提供回填与回滚方案。
3. 唯一性、幂等与资金安全约束必须有数据库级兜底，不能只靠应用层。
4. 历史账务与审计记录不得因配置对象变更而失去关联。
