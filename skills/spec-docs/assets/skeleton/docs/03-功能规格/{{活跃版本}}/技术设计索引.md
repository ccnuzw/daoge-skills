## Review 门禁

1. 每个公开或领域入口必须写明签名、前置条件、后置条件和副作用。
2. 每个关键判断、状态迁移、事务或外部副作用必须有唯一分支 ID。
3. 每个分支 ID 至少映射一个功能 AC；关键用户链路还要映射 E2E 或发布门禁。
4. 分支 ID 只增不改；分支变化时同步功能 AC 与端到端用例矩阵。
