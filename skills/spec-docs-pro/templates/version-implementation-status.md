## 状态定义

| 状态 | 定义 | 标准 |
| --- | --- | --- |
| 规划中 | 功能主文档已创建，尚未开始实现 | 规格 Ready，无代码 |
| 开发中 | 已开始实现，未满足全部验收 | 有部分代码，AC 未全通过 |
| 本地验证 | 本地测试通过，缺生产证据 | 本地测试通过，未部署生产 |
| 待验收 | 实现和自动化完成，等待业务验收 | 代码完成，等待最终确认 |
| 已完成 | 需求、实现、测试、文档、验收全闭环 | 所有 AC 通过，有生产证据 |
| 阻塞 | 存在明确外部依赖，当前无法继续 | 依赖未就绪 |

## 维护规则

1. 每次功能状态变更必须更新此文档
2. 按时间倒序排列（最新在最上方）
3. 验证证据必须详细（命令+结果+覆盖）
4. 剩余工作必须具体可执行
5. 每周更新一次功能状态汇总表
6. 里程碑状态每两周评估一次
