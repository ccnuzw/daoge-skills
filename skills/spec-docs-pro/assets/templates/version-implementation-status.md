## 状态定义

| 状态 | 含义 | 进入条件 |
| --- | --- | --- |
| 规划中 | 规格已登记，尚未开始实现 | 功能主文档存在 |
| 开发中 | 已开始实现，AC 未全部通过 | 有代码提交 |
| 本地验证 | 本地或 CI 自动化通过，缺预发/生产证据 | 全部 AC 本地通过 |
| 待验收 | 实现与自动化完成，等待业务或预发验收 | 预发环境证据 |
| 已完成 | 需求、实现、测试、文档、验收全部闭环 | 生产或发布门禁证据 |
| 阻塞 | 依赖未就绪，无法继续 | 写明阻塞原因与解除条件 |
| 已废弃 | 不再交付，编号保留不复用 | 有对应决策 |

“存在代码”不等于“已完成”；静态核验不等于测试通过；本地 mock 不等于生产验证。
