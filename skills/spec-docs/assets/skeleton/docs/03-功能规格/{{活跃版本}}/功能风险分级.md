## 执行规则

1. 任一功能没有技术设计或分支未映射 AC 时，不满足 Definition of Ready。
2. 标准风险功能命中“重新深度评审触发条件”后，必须先更新本表和技术设计，再进入开发。
3. 技术设计只冻结关键执行逻辑，不复制 API 字段或数据模型；冲突时按权威来源和决策流程处理。
4. `Design Ready` 只表示设计输入闭环；目标测试文件存在、执行和证据状态由功能主文档的验收与实现章节记录。
