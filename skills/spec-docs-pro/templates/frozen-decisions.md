## 决策模板

复制以下模板添加新决策：

```markdown
## D{编号} {决策标题}

- 状态：已冻结
- 日期：{YYYY-MM-DD}
- 背景：{问题陈述和上下文}
- 备选方案：
  - A. {方案描述}：{优点} / {缺点}
  - B. {方案描述}：{优点} / {缺点}
  - C. {方案描述}：{优点} / {缺点}
- 决定：{选择方案 X}
- 理由：
  - {理由 1}
  - {理由 2}
  - {理由 3}
- 影响：
  - 功能 {编号}：{影响描述}
  - 接口：{影响描述}
  - 数据：{影响描述}
  - 测试：{影响描述}
- 风险：
  - {潜在风险 1}
  - {潜在风险 2}
- 实施检查清单：
  - [ ] 更新受影响功能文档
  - [ ] 更新公共契约文档
  - [ ] 创建/修改 migration
  - [ ] 更新代码实现
  - [ ] 更新测试用例
  - [ ] 通知相关开发者
- 重新评估条件：{什么情况下需要重新考虑这个决策}
```

## 维护规则

1. 新决策编号递增，不跳号
2. 被取代的决策保留原文，更新状态指向新决策
3. 每个决策必须有明确的影响范围
4. 实施检查清单必须完成后才能标记为已实施
5. 重大决策同时创建 ADR 记录
