## 冻结决策 vs ADR

| | 冻结决策 | ADR |
| --- | --- | --- |
| 回答 | 结论是什么、谁受影响 | 为什么这样选、放弃了什么 |
| 形态 | 编号 `D001` 的短条目，含状态与取代关系 | 单文件，含背景/备选/理由/后果 |
| 更新 | 状态可变为“已被 Dxxx 取代” | 保持原文，追加新 ADR |
