## 🎓 关键学习

通过深度分析 TUZAI 项目 40+ 份样例文档，我们发现：

1. **追踪精度至关重要**：从 PRD 到分支 ID 到 AC 到测试的完整链路
2. **验证记录必须详细**：环境+命令+结果+覆盖，不能只写"测试通过"
3. **分支 ID 是追踪核心**：连接设计、验收、测试的关键
4. **表格是规范载体**：AC 逐项测试设计表、分支到测试追踪表不可省略
5. **证据驱动状态**：状态变更必须有可复现的验证证据
