# {{活跃版本}} 部署运行手册

## 1. 发布输入

必须记录：commit、build_id、制品 digest、migration 起止版本、配置版本、发布时间窗和负责人。

## 2. 预检查

1. 冻结发布分支和变更清单。
2. 验证 staging E2E 与 production-gate 必需项。
3. 检查数据库、缓存、外部依赖和 DNS/TLS。
4. 创建发布前备份并验证可读。
5. 确认[回滚手册](回滚手册.md)的兼容版本和触发条件。

生产启动前必须确认：

- 生产模式环境变量生效；不存在示例密钥或占位符。
- 秘密来自受控 secret；指标入口需要鉴权。
- 客户端登录态存储策略符合[安全基线](../安全基线.md)。

## 3. 推荐顺序

```text
备份
-> 执行向前兼容 migration
-> 部署核心服务并检查 ready 与内部接口
-> 部署入口/网关并检查关键 smoke
-> 部署后台任务并检查单批次 dry-run
-> 发布前端静态资源
-> 执行端到端 smoke
```

## 4. Smoke 清单

- 登录与受保护查询。
- 关键写操作：创建、禁用、删除保护。
- 核心业务链路一笔小额/受控调用。
- 依赖入账与流水核对（如适用）。
- health/ready、metrics 鉴权、CORS 正反例和 request_id 日志查询。

Smoke 使用专用账号与 `release_id`，不得使用真实用户数据。

## 5. 发布后观察

至少观察一个完整业务窗口，关注：

- 错误率、超时、鉴权失败。
- 缓存/数据库连接与 ready 状态。
- 未释放的锁/冻结、补偿堆积、任务失败数。
- 关键业务不变量（余额、库存、配额等）。

达到[回滚手册](回滚手册.md)任一触发条件时停止扩流并执行回退。
