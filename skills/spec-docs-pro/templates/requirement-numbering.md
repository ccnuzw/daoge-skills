# V{版本} 需求编号

本文档维护 V{版本} 的稳定需求编号分配表。编号一旦分配，终生不变；移动功能文档不能改变编号。

## 编号规则

- `V{版本}-FR-{编号}`：功能需求（Functional Requirement）
- `V{版本}-NFR-{编号}`：非功能需求（Non-Functional Requirement）
- `V{版本}-RG-{编号}`：发布门禁（Release Gate）
- `V{版本}-E2E-{编号}`：端到端验收场景
- `AC{编号}`：功能内验收条件（Acceptance Criteria）
- `B{功能编号}-{分支编号}`：技术设计分支 ID

## 维护规则

1. 新增功能必须先在此文档分配编号
2. 编号按递增顺序分配，不跳号
3. 废弃功能保留编号，标记状态为"已废弃"
4. 移动功能文档路径不能改变编号
5. 每月审查编号使用情况，确保无重复
