## 伪代码

要求：每个关键判断和副作用标注分支 ID `// B{NN}-{序号}`；显式写出事务边界、锁和错误键；外部调用放在事务外。

```text
FUNCTION {name}({params}) -> Result:
  IF NOT validate({params}): RETURN Err({error_key})             // B{NN}-01
  existing = find_by_idempotency_key(key)
  IF existing: RETURN existing                                   // B{NN}-02
  BEGIN TRANSACTION
    row = SELECT ... FOR UPDATE                                  // B{NN}-03
    IF NOT rule(row): ROLLBACK; RETURN Err({error_key})          // B{NN}-04
    {写操作}                                                     // B{NN}-05
    INSERT audit_log                                             // B{NN}-06
  COMMIT
  ENQUEUE {异步副作用}                                            // B{NN}-07
  RETURN Ok(result)
```
