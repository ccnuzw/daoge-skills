## 后续版本规则

后续版本未进入开发时，不提前复制详细文档结构，也不批量生成空接口、空数据模型或空验收文件。规划文档可以包含这些章节，但它们只表达方向。

通过版本进入开发门禁后：

1. 冻结版本范围、依赖和成功标准。
2. 分配稳定的 `Vx-FR/NFR/RG` 编号。
3. 按可独立验收目标建立中文功能主文档。
4. 完成风险分级，高风险功能建立独立技术设计。
5. 建立机器可读接口契约、公共数据模型、端到端验收和发布证据空间。
6. 在版本实现状态中记录 Ready 日期、评审角色、未决风险和证据位置。

## 使用方式

1. 查产品范围：先看版本总览或后续版本规划。
2. 查一项能力如何跨版本增强：看功能演进矩阵。
3. 查具体行为：进入对应功能主文档。
4. 查当前完成度：看版本实现状态，不从规划文档推断。
5. 查接口和数据：看技术架构中的公共契约，再看功能主文档的相关章节。
6. 查验收和发布：进入测试与发布目录。
7. 查取舍原因：进入决策记录和 ADR。
