# 机器可读示例与夹具

本目录存放公共契约的**可执行示例**：制品样例、请求/响应夹具、校验用 fixture 等。示例用于证明契约可解析、可校验，不建立第二套规则。

## 目录约定

```text
示例/
  <示例名>/
    README.md        # 示例说明：适用契约、来源、兼容边界
    <制品文件>        # 例如 driver.yaml / schema.json / request.json
    fixtures/        # 可选：校验输入
```

## 规则

1. 每个示例必须在 README 中说明对应的权威规范；冲突时以规范为准。
2. 示例变更时同步检查关联规范与校验命令。
3. 示例不得包含真实密钥、账号或用户数据。
4. 校验命令写进示例 README，便于 CI 或 `check-docs` 之外的结构校验复用。
