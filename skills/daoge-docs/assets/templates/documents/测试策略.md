## 风险到测试映射

| 风险 | 最低测试组合 | 必须注入的失败 | 必须核对的副作用 |
| --- | --- | --- | --- |
| 标准读操作 | 单元 + API/前端 | 不存在、无权、依赖不可用 | 无意外写入或敏感泄露 |
| 标准写操作 | 单元 + 数据库集成 + API + E2E | 重复、冲突、部分失败 | 状态、审计和幂等记录 |
| 资金/配额 | Decimal/纯规则 + 并发事务 + E2E | 余额不足、重复、回滚、补偿失败 | 余额、流水、凭证和对账不变量 |
| 权限/秘密 | 授权单元 + 契约 + 安全回归 | 越权、过期、轮换、降级 | 零业务副作用和脱敏日志 |
| 外部副作用 | 契约 + 集成 + E2E | 超时、未知结果、重试、回调重放 | 请求次数、幂等和补偿终态 |
| 迁移/删除 | 迁移测试 + 恢复演练 | 中断、旧版本并存、回滚 | 数据完整性、兼容和可恢复性 |

每个功能还必须覆盖：成功、输入边界、未登录/错误角色、对象所有权、不存在/禁用/过期、重复、并发、依赖失败、回滚、日志脱敏，以及适用的前端完整状态。

## 数据与夹具

- 每个批次使用唯一 `run_id`，对象和幂等键可追溯到用例。
- 时间、随机、功能开关和外部状态必须可控制并记录实际取值。
- 夹具通过公开入口或受控 seed 建立，不得直接改核心业务表制造成功终态。
- 清理只处理当前 `run_id` 资产；失败批次按证据策略保留。

## 失败和缺陷处理

| 失败类别 | 批次结果 | 必须保留 | 是否允许继续 |
| --- | --- | --- | --- |
| 业务断言失败 | failed | 首个失败步骤、request_id、状态和副作用 | 按风险决定；资金/数据不变量失败立即停止 |
| 环境前置失败 | environment_failed | 健康检查、配置摘要和受影响用例 | 否 |
| 依赖替身失效 | invalid | 替身健康、请求计数和受影响用例 | 否 |
| 证据缺失 | evidence_incomplete | 已执行命令和缺失项 | 可调试，不得通过门禁 |
| 测试生成器饱和 | generator_limited | 生成器资源和到达率 | 不得推断服务容量 |

失败报告不得被后续成功批次覆盖；修复后必须使用新批次 ID。
