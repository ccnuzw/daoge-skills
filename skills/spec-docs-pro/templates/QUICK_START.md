# 快速开始指南

## 🚀 5 分钟快速开始

### 适用场景
- ✅ 标准项目（10-30 个功能）
- ✅ 已有基础文档结构
- ✅ 想快速生成文档浏览器

### 不适用场景
- ❌ 从零开始的新项目 → 请阅读完整的 mode-4-pure-agent.md
- ❌ 需要深度定制 → 请阅读 MASTER_GUIDE_INDEX.md

---

## 第一步：准备文档（5 分钟）

### 必需文档清单
```
docs/
├── 01-项目概览/
│   └── README.md
├── 02-产品与版本/
│   ├── 版本路线图.md
│   └── 功能演进矩阵.md  ← ⚠️ 必须用表格格式
└── 03-功能规格/
    └── V1/
        └── *.md
```

### ⚠️ 关键：演进矩阵格式检查
```bash
# 检查演进矩阵是否用表格
grep "^|" docs/02-产品与版本/功能演进矩阵.md | wc -l
# 如果返回 < 10，格式错误！需要改为表格格式
```

**正确格式**：
```markdown
## 3. Provider 能力演进

| 阶段 | 增量说明 | 依赖 | 完成判定 | 状态来源 |
|------|---------|------|---------|---------|
| V1 基础适配 | ... | ... | ... | ... |
```

**错误格式**：
```markdown
### 3.1 V1 基础适配
**用户价值**：...
```

## 第二步：生成浏览器（1 行命令）

### 提示词
```
用 spec-docs-pro 为 [项目名] 生成文档浏览器。

关键要求：
1. DOCS 数组必须有 phase、soft、goal 字段
2. FEATURE_TRACKS 必须有 title 和 overview 字段
3. FEATURE_BROWSER_DATA 的 title 不包含 id
```

### 打开浏览器

```bash
open docs/90-参考资料/产品文档浏览器.html
```

## 常见问题快速修复

### 问题 1：文档头部显示 undefined
```bash
read skill://spec-docs-pro/templates/DOCS_ARRAY_FORMAT.md
```
**原因**：DOCS 数组缺少 phase 或 goal 字段

### 问题 2：时间线显示"未分配阶段"
```bash
read skill://spec-docs-pro/templates/TIMELINE_UNDEFINED_STAGES.md
```
**原因**：演进矩阵格式错误或 FEATURE_TRACKS 缺少 title

### 问题 3：功能 ID 重复显示
**原因**：FEATURE_BROWSER_DATA 的 title 包含了 id
**修复**：title 只保留功能名称

## 项目规模建议

### 小项目（< 10 功能）
**演进矩阵**：1-2 个能力主线即可
```markdown
| 阶段 | 增量说明 | 依赖 | 完成判定 | 状态来源 |
|------|---------|------|---------|---------|
| V1 基础功能 | 核心功能实现 | - | 基础可用 | V1 规格 |
```

### 中型项目（10-30 功能）
**演进矩阵**：3-6 个能力主线
**建议**：按领域划分（身份、数据、业务、集成等）

### 大型项目（50+ 功能）
**演进矩阵**：6-10 个能力主线
**建议**：添加跨版本总览表

```markdown
| 阶段 | 增量说明 | 依赖 | 完成判定 | 状态来源 |
|------|---------|------|---------|---------|

```
