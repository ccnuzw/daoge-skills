# {{VERSION}} E2E 测试夹具

## 夹具原则

- 所有动态值携带唯一 `run_id`；对象、请求和幂等键可回溯到用例 ID。
- 时间、随机种子、外部响应和失败注入必须确定且记录实际值。
- 优先通过公开入口建立业务状态；受控 seed 只能建立不可由公开入口创建的基础设施数据。
- 不直接写核心状态、余额、权限、审计或外部回调终态来制造成功。
- 金额使用 Decimal 字符串，时间使用带时区 ISO-8601，秘密只从测试 secret 注入。

```text
run_id=<version>-<timestamp>-<random-suffix>
object_name=e2e-<case_id>-<run_id>
idempotency_key=<case_id>-<run_id>-<sequence>
```

## 敏感信息边界

- 报告、截图、快照和日志不得包含密码、Token、Key、私钥、完整签名 URL 或未脱敏个人数据。
- 允许记录稳定对象 ID、秘密指纹、安全前缀和受控证据路径。
- 失败日志保存前执行秘密扫描；发现泄露时停止批次并按安全事件处理。
