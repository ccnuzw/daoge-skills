## 0. 前置

### 0.0 性质与今日实测

批 D 不是加功能，是**把三面上的东西放对位置**：资产是后台，交付是记录与领取的家，资料三页长一个样。

**实测（编单时）**：
- 资产页：`PageHeader` 已有后台定位句（`ASSET_BACKSTAGE_COPY`）✓；工具条已齐（范围/类型/每页/全选本页/回收站/导入）✓；
  **但「已选图片」条上有挑图主路径**：`预览挑图`（title 明说「空格保留，X 不采用」）+ `基于已选继续`（`CreativeActionLauncher`，含「不采用」评审动作）。
- 交付页：`PageHeader` ✓、历史在下方同屏 ✓；**步骤条 `<ol>` 无条件常显**（§7.5 要求「仅在有草稿时展开」）。
- 资料三页：注册表里已全是 `narrow` ✓；`creative-library` 已有「索引 + 详情」两栏（`library-workbench`）✓；
  `shared-assets` 只有网格**没有页内搜索/筛选**（§7.6 要「次：页内搜索与筛选」）；三页的筛选位不统一。
- 疑难：`narrow` ✓（注册表）；设置：全局对话框（standard 宽），640 下可用性待核。

- **A4：交付发起挂选中**——画布 / 资产 / 检查器选中已保留成果就能发起；批 D 收敛时**不许把发起收回交付页**。
- 画布与检查器的评审（保留/不采用/照它再来）**原样保留**——批 D 只清资产页的复制品。

- 深链不变量：`?view=assets|deliveries|library|shared-assets|guide|troubleshoot` 全部仍可直达。

## 1. 目标（可验收的一句话）

资产页一眼看出是**后台**（导入、整理、去重、回收），挑图不在它上面；交付页没草稿时**只有一行**，有草稿才展开三步；
资料三页（规则资料 / 共享素材 / 创作手册）**栏宽、行高、页内筛选位一致**；疑难与设置在 640 下可完整操作。

## 2. 任务分解

### D1 · 资产页：后台收口（挑图主路径清掉）

1. 「已选图片」条：`预览挑图` → **`放大查看`**（title 改为「放大查看；挑图在创作平台」）；去掉 `基于已选继续`
   （`CreativeActionLauncher` 含「不采用」，是画布评审的复制品）；保留 `去交付`、`打包下载`、`清空`。
2. 查看器（`ImageInspectorDialog`）：入口来自 assets/trash 时是**只读**——不渲染「选为成果」勾选、动作条与
   空格/X 评审键；顶栏只留缩放/铺满/关闭。
3. 资产卡片的浮层动作核对：只允许 放大/下载/来源（不得出现保留/不采用）；缺则删。
4. 工具条六件与页头定位句核对（已在，不动）。

### D2 · 交付页：步骤条按需展开，历史同屏

`stepsOpen = 选中数 > 0 || 正在创建 || 已冻结`；不满足时步骤条收成一行摘要（「还没有草稿 · 去选图」+ 按钮）。
历史（`creator-delivery-history`）保持在同屏下方（核对，不改位置）。

### D3 · 资料三页：同一版式与筛选位

- 三页统一：`PageHeader` 之后**紧跟**一个页内筛选条（`data-block="page-filter"`）；
- `shared-assets` **补页内搜索**（按名称/标签过滤网格）；
- `library`/`guide` 的既有筛选条挂上同一个钩子（位置本就相符，只对齐口径）。

### D4 · 疑难与设置：三档断点 + token

- 疑难页：`narrow`（注册表）✓，核对 640 下三段式可读；
- 设置对话框：640 下可完整操作（宽度/内边距走 token 与既有断点；密钥与 Base URL 仍 write-only）。

### D5 · 守卫与收尾

G24–G27 写入并确认会咬（至少对 G24 做一次反证）；全量回归 + lint + build；三面各截一张图入档。

2. 交付页：没选图时步骤条收成一行（含「去选图」）；选了图/有草稿时三步展开；历史仍在同屏下方；

5. 画布上的评审（保留/不采用/照它再来）与资产页的「去交付」都还在（A4 不倒退）。
