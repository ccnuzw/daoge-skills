## 正确性与通过规则

- [ ] 每个请求拥有唯一 `run_id + request_id`。
- [ ] 成功计费、用量、消费和余额终态一一对应，重复请求不重复副作用。
- [ ] 非计费操作不创建 Hold 或消费流水；所有 Hold 已结算或释放。
- [ ] 预期容量拒绝不增加 Platform/上游请求，非预期错误不被伪装为容量拒绝。
- [ ] 过载解除后延迟、错误、in-flight、队列、RSS 和连接池在批准窗口内恢复。
- [ ] 任一资金、用量、权限或数据不变量失败都使批次失败，即使性能指标达标。
