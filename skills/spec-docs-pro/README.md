# Spec-Docs-Pro: 规格驱动开发设计顾问

**版本**: v4.0.0  
**状态**: 重大更新 - 真正定制化浏览器

## 简介

Spec-Docs-Pro 是一个**规格驱动开发设计顾问**，不是文档生成器，而是**思考伙伴、问题发现者、架构评审者**。

基于 TUZAI 项目的成熟实践（84KB 冻结决策 + 39 个功能规格 + 完整追踪体系），帮助开发者在设计阶段发现问题、深度思考、建立完整的追踪链路。

---

## 核心理念

### 深度思考 > 格式规范

**不是填表，而是引导思考：**

❌ "这个功能需要 6 个 AC"  
✅ "如果用户创建成功但余额账户创建失败，会怎样？"

❌ "记得加分支 ID"  
✅ "有没有考虑并发场景？如何防止超扣？"

### 发现问题 > 描述需求

**在设计阶段发现漏洞：**

- 🔴 多个写操作 → 原子性问题（半成品数据）
- 🔴 并发访问 → 竞态条件（超扣、重复）
- 🔴 外部调用 → 超时、重试、补偿
- 🔴 状态变更 → 非法状态转换
- 🔴 金钱权限 → 高风险，需要独立设计

### 完整追踪 > 独立章节

**每个设计都能追溯到源头：**

```
PRD → 功能规格 → 业务规则 → 冻结决策 → 技术设计 → AC → 测试 → 验证证据
```

### 文档浏览器（v4.0 - 真正定制化）

**v4.0 核心改进：**
- ✅ **不再是模板套用**：深度分析文档结构，动态生成所有数据
- ✅ **自动识别项目**：从文档中提取项目名称和结构
- ✅ **智能数据提取**：
  - 版本信息（当前/规划/历史状态）
  - 功能列表（编号、标题、风险、状态）
  - 决策记录（关键口径）
  - 能力主线（演进轨迹）
- ✅ **真正定制化**：所有数据结构（DOCS、DECISIONS、FEATURE_TRACKS等）动态生成
- ✅ **智能降级**：即使文档不完整，也能生成有用的浏览器

**浏览器功能：**
- ✅ 5 个视图：总览/阅读/图谱/演进/时间线
- ✅ 智能文档导航（按版本和目录分组）
- ✅ 全文搜索和功能筛选
- ✅ 阅读进度跟踪
- ✅ 完整 Markdown 渲染

**对比 v3 版本：**

| 特性 | v3 (旧版) | v4 (新版) |
|------|-----------|-----------|
| 数据来源 | 硬编码 TUZAI 数据 | 真实分析文档 |
| 项目名称 | 字符串替换 | 自动识别提取 |
| DOCS 数组 | 部分动态 | 完全动态 |
| DECISIONS | 硬编码 | 从文档提取 |
| FEATURE_TRACKS | 硬编码 | 从演进矩阵提取 |
| 版本信息 | 硬编码 | 从文档分析 |
| 适用范围 | 仅 TUZAI 结构 | 任意项目结构 |
### 9 个文档模板

初始化时自动生成，每个都包含完整结构和占位符：

1. **产品蓝图.md** - 产品定位、目标用户、核心价值
2. **版本路线图.md** - 版本规划、时间线
3. **版本规格说明.md** - 版本编号规则、文档结构
4. **全版本产品与交互约束.md** - 跨版本共享的约束
5. **功能演进矩阵.md** - 能力主线的演进路径
6. **V1-版本总览.md** - 版本目标、功能范围
7. **V1-产品需求.md** - 需求列表
8. **V1-实现状态.md** - 功能开发进度
9. **版本进入开发门禁.md** - 开发启动条件

### 5 大高风险场景自动识别

在创建功能规格时，自动识别并引导设计：

1. **多个写操作** → 引导思考原子性、事务边界
2. **并发访问** → 引导思考竞态条件、锁策略
3. **外部调用** → 引导思考超时、重试、补偿
4. **状态变更** → 引导思考状态机、非法转换
5. **金钱权限** → 强制要求独立技术设计

## 快速开始

### 安装

**全局安装（推荐）：**

```bash
# 固定版本
npx skills add https://github.com/ccnuzw/daoge-skills/tree/spec-docs-pro-v1.0.0/skills/spec-docs-pro -a codex

# 跟随 main 分支
npx skills add ccnuzw/daoge-skills -a codex -s spec-docs-pro
```

**项目级安装：**

```bash
cd /your/project
npx skills add ccnuzw/daoge-skills -s spec-docs-pro
```

重启 Codex 后生效。

### 使用示例

#### 1. 初始化项目文档体系

```
使用 spec-docs-pro 为我的项目初始化文档体系
```

**会生成：**
- 7 层目录结构
- 9 个核心文档（带完整内容）
- 约 25+ 个文件

#### 2. 创建功能规格

```
使用 spec-docs-pro 创建功能规格
```

**AI 会引导你：**
- 深度思考功能边界
- 发现设计漏洞（原子性、并发、外部调用等）
- 生成完整的功能规格文档
- 包含 AC 逐项测试设计表、分支追踪、验证记录

#### 3. 生成文档浏览器

```
使用 spec-docs-pro 生成文档浏览器
```

**会自动：**
- 扫描所有文档
- 生成交互式 HTML 浏览器
- 动态生成 4 个 SVG 图表
- 输出到 `docs/90-参考资料/产品文档浏览器.html`

#### 4. 记录架构决策

```
使用 spec-docs-pro 生成 ADR
```

**AI 会引导你：**
- 收集决策背景
- 评估备选方案（优缺点、成本）
- 生成完整 ADR 文档（包含后果分析、风险评估）

#### 5. 更新需求追踪矩阵

```
使用 spec-docs-pro 更新需求追踪矩阵
```

**会自动：**
- 扫描所有功能文档
- 提取功能→接口、功能→数据、功能→E2E、AC→测试的映射
- 生成完整追踪矩阵
- 检查完整性，标注缺失项
