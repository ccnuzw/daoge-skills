## 版本完成口径

单个功能完成不代表版本完成。只有**已进入交付范围**的功能主文档达到各自完成定义、跨功能 E2E 全部通过、发布门禁完成目标环境验证后，版本才能按范围标记完成。

登记编号不等于进入交付范围：处于设计扩展或规划中的功能（例如“设计稿已定、运行时未开发”）必须显式标注状态，不能因文档登记视为已实现或已进入收费发布。
